CHAUKA – so startest du das Projekt auf deinem Rechner
======================================================

Du brauchst nur Node.js. Sonst nichts – kein Passwort, keine Datenbank,
keine .env-Datei. Alle Daten liegen als CSV im Ordner "public".


1) Node.js installieren (einmalig)
----------------------------------
https://nodejs.org  ->  die "LTS"-Version herunterladen und installieren.
Danach Terminal neu öffnen. Prüfen mit:

    node -v


2) Ordner entpacken und im Terminal hineingehen
-----------------------------------------------
Tipp: "cd " ins Terminal tippen (mit Leerzeichen), dann den Ordner aus
dem Finder/Explorer ins Terminal ziehen und Enter drücken.

    cd /pfad/zu/chauka-projekt


3) Einmalig die Pakete installieren
-----------------------------------
    npm install

Dauert beim ersten Mal ein paar Minuten.


4) Seite starten
----------------
    npm run dev

Dann im Browser öffnen:  http://localhost:3000
Beenden: im Terminal Strg + C (Mac: Control + C).
