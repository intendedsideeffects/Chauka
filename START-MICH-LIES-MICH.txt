CHAUKA – so startest du das Projekt auf deinem Rechner
======================================================

Du brauchst nur Node.js. Sonst nichts – kein Passwort, keine Datenbank,
keine .env-Datei. Alle Daten liegen als CSV im Ordner "public".


1) Node.js installieren (einmalig)
----------------------------------
https://nodejs.org  ->  die "LTS"-Version herunterladen und installieren.
Danach Terminal neu öffnen. Prüfen mit:

    node -v

Da sollte sowas wie v20.x oder v22.x stehen.


2) Ordner entpacken
-------------------
Die ZIP irgendwohin entpacken, wo du sie wiederfindest, z.B. nach
Dokumente/chauka-projekt


3) Im Terminal in den Ordner gehen
----------------------------------
Tipp: "cd " ins Terminal tippen (mit Leerzeichen), dann den Ordner aus
dem Finder/Explorer ins Terminal ziehen und Enter drücken.

    cd /pfad/zu/chauka-projekt


4) Einmalig die Pakete installieren
-----------------------------------
    npm install

Dauert beim ersten Mal ein paar Minuten und lädt ca. 500 MB in den
Unterordner node_modules. Das ist normal.


5) Seite starten
----------------
    npm run dev

Dann im Browser öffnen:  http://localhost:3000

Beenden: im Terminal Strg + C (auf dem Mac: Control + C).


Was noch gut zu wissen ist
--------------------------
* Änderungen an Dateien im Ordner "src" siehst du sofort im Browser,
  Seite muss nur kurz neu laden.

* "npm run build" baut die Seite genauso, wie Vercel sie baut. Wenn das
  ohne Fehler durchläuft, würde auch ein Deploy durchlaufen.

* Die blauen und gelben Punkte kommen aus zwei Dateien im Ordner public:
      public/Disaster_Dataset_with_Summaries_fixed.csv   (blaue Punkte)
      public/Climate_Resistance_Tooltips.csv             (gelbe Punkte)
  Wenn du dort Zeilen änderst oder ergänzt, ändern sich die Punkte.
  Es gibt keine Datenbank mehr, an der etwas kaputtgehen kann.

* Mehr zum Aufbau steht in der README.md (auf Englisch).
